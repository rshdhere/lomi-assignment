# Reviewer walkthrough for the hosted demo

Start with the deployed dashboard URL and local copies of [the original invoice](../fixtures/documents/invoice-001.pdf) and [the revised invoice](../fixtures/documents/invoice-001.v2.pdf). The acceptance result is five reviewed fields on invoice v1, followed by three carried reviews and two pending fields on v2.

| Step                    | In the browser                                                                                                                                                                                                                                                                 | What to check                                                                                                                                                                                                                                                                             |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. Open the library     | Visit the dashboard in a fresh browser session.                                                                                                                                                                                                                                | A freshly seeded deployment shows one invoice, one lease and one market report, each at v1. Each entry shows extraction status and review progress.                                                                                                                                       |
| 2. Ingest a new PDF     | Click **Upload PDFs**, choose `invoice-001.pdf`, select **Invoice**, and submit. Keep the newly uploaded invoice selected for steps 3–6.                                                                                                                                       | The upload is accepted and extraction continues asynchronously. The dashboard updates to **Extracted**. Fast jobs can finish between polls.                                                                                                                                               |
| 3. Review the original  | Compare all five fields against their adjacent quotes. Approve the invoice number, issue date, due date and total. Use **Correct value** on the vendor to record “Meridian Office Supplies LLC” with the optional note “Normalized capitalization.” Click **Save correction**. | Progress reaches 5 of 5 reviewed. The vendor shows the correction alongside the original extraction and quote. Refresh and confirm the reviews persist.                                                                                                                                   |
| 4. Upload the revision  | Confirm the open detail is the same invoice you reviewed. Click **Upload revision** inside that document and choose `invoice-001.v2.pdf`.                                                                                                                                      | The same document advances to v2. While extraction runs, further revisions are blocked.                                                                                                                                                                                                   |
| 5. Inspect what changed | When v2 is **Extracted**, select **Pending only**.                                                                                                                                                                                                                             | Exactly two fields need attention. Due date changed from **2025-10-14** to **2025-11-13**. Total changed from **$5,230.29** to **$6,126.45**. Each shows its prior value and review. Clear the filter to see the invoice number, issue date and corrected vendor marked **Carried over**. |
| 6. Verify history       | Use **Viewing** to open v1. Then return to **Latest (v2)** and approve the two changed fields after checking their quotes.                                                                                                                                                     | V1 retains the original due date, total, evidence and vendor correction. V2 now shows 5 of 5 reviewed.                                                                                                                                                                                    |
| 7. Review a genuine gap | Open the seeded **Market report excerpt — Eastport Rental Market, Q3**, v1. Inspect **Median household income** and the parsed text. On a fresh seed, click **Confirm gap**.                                                                                                   | The report omits income. The field has a gap reason, and confirming it records the review without inventing an amount. The seeded lease is also available for reviewing its five lease-specific fields.                                                                                   |

**Failure and recovery.** If extraction fails, the document should display **Failed**, a reason and **Retry extraction**. Once the cause is resolved, retry the same version. Its eventual result should have one row per expected field. The operator verifies worker interruption and Redis loss on the isolated integration stack while the reviewer checks the resulting status and retained reviews. [Recovery test](../tests/integration/README.md)

**Optional Q&A demo.** With the invoice selected, click **Ask documents**, choose that invoice under **Search in**, and ask “What is the unit price for the MA-2 monitor arm?” The fixture lists **$89.00** per unit. Open the citation and check its document, version and source passage. This demonstrates the SPEC extension after the assignment's review flow.

**Before sharing the URL.** Build the images from the final source, configure the public HTTPS API and signed-upload endpoints and allow the dashboard origin on both services. Run the steps above from a browser outside the host using a fresh demo dataset. A signed upload link containing localhost points to the visitor's own computer.
