The last question isolated a retrieval defect. The existing lexical lookup requires a match for all search terms or a matching retrieved chunk containing the quote. A read-only SQL comparison on the fresh v2 showed that a search including “reviewer corrected vendor name” matched zero reviewed fields. Matching the explicit field label against the original question selected only `vendor_name`. An unrelated question naming a sales representative selected zero fields. The candidate adds this scoped lookup and regression checks for both questions. A temporary process loaded the two candidate source files in memory, used a read-only connection to the staging database, and asked the original question again with the live provider. The answer contained the correction and cited the reviewed v2 vendor field. The JSON records both source hashes. The serving application continued to run the manually published images during this check.
