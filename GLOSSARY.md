# Review vocabulary

| Term                | Meaning                                                                                                               |
| ------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Document            | An invoice, lease or market report that a reviewer follows across revisions.                                          |
| Version             | One submitted PDF in a document’s history. Its source and extraction belong together.                                 |
| Expected field      | A named value a reviewer expects for this kind of document, such as the due date of an invoice.                       |
| Evidence            | The exact passage of this version’s text cited for an extracted field.                                                |
| Gap                 | An expected field with a null extracted value and a reason explaining the missing or invalid evidence.                |
| Correction          | A reviewer’s replacement value and optional note, kept alongside the original extraction.                             |
| Carried-over review | A prior approval or correction applied to the same field in the next version because its verified quote is unchanged. |
| Batch               | A group of PDF uploads the reviewer submits for extraction together.                                                  |
